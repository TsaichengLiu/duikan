# 對勘

同源文本比對工具（macOS）：找平行段落、多本逐字對校、生成校勘記與異文表、統計各本讀法的分合。簡繁異體互通，忽略標點，適合未經句讀的古籍。

程序只做**確定性**的工作——文字歸一、對齊、列出異文、計數；異文的性質、正誤、是否「共同錯誤」，由你或 LLM 判斷，程序再據你的判斷重算拉赫曼式的統計。方法論見 App 內「方法說明」（`app/static/guide.html`）。

## 使用

需要 macOS 與 Xcode 命令行工具（`xcode-select --install`；用到 `swiftc` 和系統自帶的 `/usr/bin/python3`，不需要其他第三方包）。在本目錄運行 `./build_app.sh --install`，即構建並安裝到「應用程序」文件夾（App 運行中也可以更新，重新打開後生效）。打開後，左上「加入文件」選 PDF（須有文字層）、Word、TXT 等，或把文件拖進窗口（按原路徑加入，與「加入文件」相同；早先拖入時保存的副本，啟動時會按原文件名找回原文件並改為指向它），或「貼上文字」。勾選要參與比對的文本；雙擊文本可改簡稱（甲乙丙……，校記中用）、名稱，以及比對範圍（PDF 頁碼、起止文字）。

- **兩本對讀**：找出兩本之間所有平行段落（不論次序），點圖顯示抄錄、節錄、移位的形態；每段逐字對照，左右欄不同之處分色標出，字形差異（繁簡、異體）加點線。可匯出段落列表（CSV）和對照表（Markdown）。適合史源追蹤。
- **多本對校**：選底本和校本，逐字對齊後，分「同文、異文、校記、統計」四頁：
  - 同文：以底本為座標，各本（歸一後）逐字相同的文字按「哪幾本相同」分段——同文分佈（每種組合共有多少字，點擊篩選）與同文段落（可按字數排序、設下限，雙擊看各本原文）；另列底本讀法不同而兩本以上彼此相同的文字（共有的增文、改字），供史源考察；可匯出 Excel／CSV，或生成「史源分析稿」交給 LLM；
  - 校記：底本正文附異文編號，右側是「『某』，乙本作『某』」「『某』下，丙本有『某』」式的中性校記；
  - 異文：每條異文各本讀法並列；點某本讀法＝定為正讀，★＝指示性錯誤，可寫備註；
  - 統計：各本概況、讀法相合率、讀法分組（未經判斷）；判斷之後給出共同錯誤（Bindefehler）、分離錯誤（Trennfehler）、可能的轉抄本。
  - 匯出校勘記（txt）、異文表（CSV）、全部數據（JSON）。
- **給 LLM**（各頁「匯出」選單最後一節）：不連接任何服務，只生成可分享的 Markdown 文檔（角色、任務、數據、回答格式俱全），複製或存為 .md／.txt 後交給任何 LLM：判讀稿（可選全部、未判斷、當前篩選或編號區間）、史源分析稿（同文分佈＋部分本子共有的段落）、譜系討論稿、兩本對讀的段落分析稿、檢索結果分析稿。判讀稿的回答可整個貼回「導入」，表格中的正讀與指示性錯誤即成標記。
- **檢索**：輸入一句或一段話（輸入即檢索），在各文本中找出它的近似出現處（模糊：容許異文、脫衍，Myers 位向量近似匹配；精確：歸一後字字相同），命中處全部列出（每本逾 3000 處才截斷），可按原文順序或相似度排列、按文本分組或混排；雙擊一處看原文上下文（彈窗裡可逐處前後切換），勾選幾處後逐字對校；各處片段先按參照片段的範圍自動對準。結果可整體或逐條匯出 Word、Excel、TXT。
- **右鍵與鍵盤**：文本列表右鍵可設定、勾選、放入兩本對讀或設為底本、打開原文件、在訪達中顯示、移除；段落、對照表、校記、異文表、同文、檢索結果、總覽各有相應的右鍵菜單。列表中單擊選中後 ↑↓ 逐條移動，回車相當於雙擊。
- **原文預覽的匯出**：各本並排的原文上下文可匯出 Word（相同文字淡綠、所選處底線）、Excel、Markdown、TXT 或複製；PDF 原件當前頁可連同標注存為 PNG。
- **原文預覽**：在對照表、校記、異文表、檢索結果中雙擊，顯示各本在該處的原文上下文（相同文字淡綠，所選處金色底線）；PDF 可切換「原件」：各頁上下相接、滾動翻頁（方向鍵、PageUp/PageDown 亦可），可縮放、按住拖動平移；PDF 有文字層時在原件上標出所選位置與相同文字（位置取自 PDFKit 文字層，掃描本須帶 OCR 層）。
- **譜系草圖**：據已判斷的共同錯誤畫樹（只把判斷畫出來，不是結論）；不相容的組列出，提示交叉傳承。
- **匯出**：Word（.docx，保留顏色）與 Excel（.xlsx）由程序直接生成，不需安裝 Office 以外的任何東西：對照表、校勘記（底本正文附上標編號＋校記）、異文表、平行段落列表、檢索結果；另有 TXT、CSV、Markdown、TEI P5 XML、CollateX 對齊表、JSON。
- **結果隨選擇而變**：換文本、勾選、範圍、設定一變，當前頁自動重算（舊結果淡出），沒有「比對」「清空」按鈕；清空即取消選擇（選「（未選）」、關掉全部校本、清空檢索框）。
- **點圖／對應帶**（可切換）：點圖橫軸左欄、縱軸右欄，斜線是相同文字；對應帶上下兩條是兩本全文，帶子連接平行段落，交叉＝移位，條上空檔＝只見於一本。拖選放大、滾輪縮放、雙擊復原、點擊選段、懸停看位置，「放大查看」開大圖；放大後向後台取該範圍的全部片段。
- **對照表**：表頭兼作圖例（左欄異文黃、右欄藍）；位置只在變化時寫出；右側差異分佈條顯示整段異文的分佈，點擊跳轉。段落列表可按兩本順序、相似度、篇幅排序（升降皆可）。
- **總覽**：勾選的文本兩兩比對，矩陣顯示「行本中有多少見於列本」。
- **比對設定**：字形歸一（精確／簡繁／異體）；忽略 PDF 頁眉頁腳（默認開）、括號夾注、數字與西文（默認忽略）；平行段落的參數（種子長度、段內空隙、段落下限、相同比例、套語上限，滑桿連續調整，另有嚴格／標準／寬鬆／短句／片語／詞語六檔預設，後三檔找十字、六字、四字的短同文，適合條目、摘錄之間的比對；在「兩本對讀」中點「參數」可邊拖邊看結果）；自定義「視同字」；避諱字對照（只用於「疑諱」提示）。

程序提示（疑倒、疑重文、疑跳脫、疑諱、移位、闕字）都只是字面規則，供判斷參考。

## 本地 MCP 服務（給 LLM 用）

`app/dk_mcp.py` 讓支持 MCP 的 LLM 客戶端（Claude Code、Claude 桌面版等）直接調用對勘做確定性的比對，判斷仍由 LLM 和你來做。

- 用對勘的文本列表、歸一設定和抽取緩存，結果與界面一致；對勘開不開都能用，對勘改了列表或設定，下次調用自動重讀。
- 只讀：不寫工作區、不改設定、不清理磁盤；也可以直接給文件的絕對路徑或幾段文字，不必先加進對勘。
- 只在 LLM 會話期間運行，標準輸入一關就退出；不常駐、不聯網、不需要 API key；兩分鐘沒有調用即釋放計算緩存。

工具：`list_texts`（文本與設定）、`read_text`（按頁或字符位置讀原文）、`search`（近似檢索一句話）、`compare_two`（兩本的平行段落）、`passage`（一段的逐字對照）、`collate`（多本對校的異文，附已做的判讀）、`shared_text`（同文分佈與同文段落）、`compare_strings`（直接比幾段文字）。結果裡【】是命中或所選處，〔〕是與對方不同的文字。

註冊到 Claude Code（所有項目可用）：

```bash
claude mcp add --scope user duikan -- /usr/bin/python3 -B /Applications/對勘.app/Contents/Resources/app/dk_mcp.py
```

Claude 桌面版：在 `~/Library/Application Support/Claude/claude_desktop_config.json` 的 `mcpServers` 裡加
`"duikan": {"command": "/usr/bin/python3", "args": ["-B", "/Applications/對勘.app/Contents/Resources/app/dk_mcp.py"]}`。

## 原理

1. 歸一：沿用通檢的字表（Unihan 18.0 + OpenCC，一字對一字），去掉標點空白，只留「字」，並記住每個字在原文中的位置——所以顯示、頁碼行碼、校記中的字形都取自原文。
2. 片段：兩本之間長度 ≥ k（默認 5）的完全相同片段（k-gram 索引，套語過多者不作種子）。
3. 平行段落：同一走向、空隙不超過 80 字（可調）的片段串成段落；只落在更強段落兩邊之內的短段（書內套語造成的交叉匹配）略去；以最長遞增子序列判斷次序是否一致。
4. 對校：在所有片段中取兩邊順序一致、總長最大的鏈為錨點，錨點間用更短的片段和編輯距離逐字對齊；各本的差異合併為校勘單位（插入點只屬一個單位，字形差異不吞併相鄰的實質差異）。
5. 統計：純計數。共同錯誤＝持同一錯誤讀法的本子組；分離錯誤矩陣＝甲錯乙不錯的次數；乙的錯誤甲全有且甲另有錯誤，即提示甲可能抄自乙。

整本書（六十多萬字）兩本對讀或對校約 2 秒；只改空隙、下限、比例時沿用已算好的種子，章節、單篇文章幾乎即時更新。

## 資源佔用（實測）

- 內存：後台服務啟動後約 14 MB；兩部六十多萬字的書互相比對時峰值約 150 MB（種子索引，持續一兩秒），之後約 70 MB；**空閒五分鐘後自動釋放計算緩存**，回到約 25 MB。單篇、章節級的文本只需幾 MB。界面（整本書對校）約 10 MB 的腳本內存。計算一次只跑一個；拖動滑桿時排隊中的舊計算會被新的取代。
- 磁盤：比對結果只在內存，不寫磁盤；原件預覽的頁面圖只在內存裡留最近 16 頁，逐字位置留最近 24 頁。會寫的只有：抽取緩存（PDF/Word 抽出的文字，每本書約 2–4 MB；文件改動或移除後的舊版本在啟動時和每 6 小時自動刪除）、貼上與拖入的文件（移除文本時一併刪除）、工作區 JSON（文本列表、設定、判讀標記；移除文本時其標記一併刪除）、日誌（超過 2 MB 輪換，只留上一份）。設定 →「磁盤與緩存…」可查看大小、清空抽取緩存。

## 結構

```
app/server.py       本地 HTTP 服務（僅 127.0.0.1，帶令牌）、工作區、後台任務
app/dk_norm.py      歸一、去標點、位置表、頁眉頁腳偵測、頁碼範圍
app/dk_align.py     片段、平行段落、最佳鏈、逐字對齊
app/dk_compare.py   兩本對讀（段落、對照表）與多本對校（校勘單位、讀法、提示）
app/dk_mcp.py       本地 MCP 服務（stdio，只讀）
app/dk_search.py    原文預覽（上下文對齊）、檢索（Myers 近似匹配）、片段對準
app/dk_office.py    生成 Word（.docx）、Excel（.xlsx）（只用標準庫 zipfile）
app/dk_extract.py   各格式抽取（取自通檢）
app/data/variants.json  歸一字表（取自通檢）
app/static/         界面（原生 JS/CSS）；guide.html 為方法說明
macos/              App 外殼（WKWebView）、dkhelper（PDFKit 抽取文字、渲染頁面）、圖標
tests/              sim_tradition.py：模擬已知譜系的抄本傳承；stats_test.js：檢驗統計與譜系草圖能否還原譜系；reattach_test.js：判讀標記隨異文單位重新對應
```

- 構建 App：`./build_app.sh` 生成 `build/對勘.app`；`./build_app.sh --install` 直接裝到 `/Applications`（不在 build/ 另留一份，免得聚焦搜索裡出現兩個「對勘」）
- 不用 App、在瀏覽器裡用：`python3 app/server.py`
- 測試：`python3 tests/sim_tradition.py <任一長文本.txt> /tmp/sim.json && node tests/stats_test.js /tmp/sim.json`
- 工作區（文本列表、設定、判讀標記）：`~/Library/Application Support/DuiKan/workspace.json`；貼上、拖入的文件存在同目錄 `files/`；抽取緩存 `~/Library/Caches/DuiKan`；日誌 `~/Library/Logs/DuiKan.log`
