一、同源文本有甚麼特點

所謂同源，指一本出自另一本，或幾本同出一個（往往已佚的）源頭。它既包括同一著作的不同抄本、刻本，也包括史源上的承襲：後書抄錄前書，或幾部書同據一份檔案、邸報、塘報、奏疏。判斷同源，可以依靠下面這些特點：

  1. 措辭成段相同，且次序大體一致。各自記述同一件事的文本，事實可以相同，措辭卻不會成段雷同；偶然相同的通常只是官銜、人名、套語。程序找「平行段落」，依據的就是這一點：先找連續五字以上完全相同的片段，再看它們能否連成走向一致的長段。
  2. 差異集中在有限的幾類。
    • 抄刻之誤：形近而訛、音近而訛、脫文、衍文、倒文，以及因上下文相同而跳過一段的「同字跳脫」（目光從一處某字跳到下一處同字）。
    • 字形差異：繁簡、異體、俗字、舊字形、避諱改字、缺筆。
    • 有意改動：刪節、增補、潤色、改稱謂、改立場（清代改竄明末史籍即其顯例）。
  3. 錯誤會遺傳。抄本繼承其底本的錯誤，又加上自己的錯誤。幾本共有的錯誤，說明它們出自同一個已有此誤的本子。這是拉赫曼方法的出發點。
  4. 覆蓋往往不對稱。節本、摘抄、引用：甲的內容大部分見於乙，乙的大部分卻不見於甲。不對稱本身不說明誰抄誰，但提示了關係的形態。
  5. 次序會被重編。編年改紀傳、紀傳改紀事本末、類書分門，原來連貫的文字被拆散重排。點圖上表現為偏離對角線的斜線段，對應帶上表現為交叉的帶子。
  6. 層累。一份文獻輾轉傳抄、改寫，後出之本每每在前本基礎上增飾。把各本按時代排好後逐對比對，增飾的層次往往清楚可見。

二、拉赫曼方法

十九世紀的古典語文學者拉赫曼（Karl Lachmann, 1793–1851）把整理抄本傳統的工作系統化，二十世紀初由馬斯（Paul Maas）《校勘學》概括為一套程序：

  1. 彙校（recensio）。盡可能找全傳本，逐字對校（collatio），記下全部異文。
  2. 據共同錯誤建立譜系（stemma codicum）。能用來判斷親緣的只有「指示性錯誤」（Leitfehler）——不易由不同抄手各自獨立產生、也不易被後人憑常識改正的錯誤。
    • 聯結性錯誤（Bindefehler）：幾本共有，證明它們同出一源。
    • 分離性錯誤（Trennfehler）：甲有而乙無，且不易改正，證明乙不出自甲。
    要點是：共享正確的讀法什麼也證明不了，那是各本從祖本繼承來的；常見的虛詞增減、簡單形近字、避諱，也容易各自發生，不足為據。
  3. 剔除轉抄本（eliminatio codicum descriptorum）。某本若完全出自另一現存之本，就沒有獨立的證據價值。
  4. 依譜系選擇讀法（examinatio, selectio）。譜系上兩支以上一致的讀法，通常就是祖本的讀法——算的是「支」，不是本子的數目。
  5. 理校（emendatio）。祖本本身有誤時，憑學識改正。

批評與修正

  • 貝迪耶（Joseph Bédier）發現學者所建的譜系絕大多數是二分的，懷疑這反映的是學者的偏好而非傳本的真實；他主張擇一善本為底本，只改明顯的錯誤。
  • 帕斯夸利（Giorgio Pasquali）指出「開放傳承」：抄手常參校多本（交叉傳承，contamination），傳本關係因而不成樹狀；又說「晚出之本不必較劣」（recentiores non deteriores）。
  • 作者生前多次修訂、刻本翻刻、補版、剜改，都會使異文不全是「錯誤」。中國刻本系統尤其如此。
  • 「何者為誤」本身是判斷；判斷又依賴對譜系的設想，有循環論證之險。所以判斷應盡量依據不依賴譜系的理由（字形、文義、史實）。

中國校勘學的對應

陳垣《校勘學釋例》的「校法四例」：對校（以同書別本對讀，相當於 collatio）、本校（以本書前後互證）、他校（以他書校本書——前人之書、後人引用，相當於間接傳承 testimonia）、理校（相當於 emendatio）。段玉裁說校書之難，難在「定其是非」，而不在照本對字——程序正好只能替你做「照本對字」的部分。陳垣的「史源學」則以後書溯前書，正是「兩本對讀」的用途。

四、使用建議

史源追蹤（兩本對讀）

  • 先用「總覽」把候選文本兩兩比一遍，看誰和誰有大量相同文字。
  • 在「兩本對讀」看點圖：橫軸是左欄文本、縱軸是右欄文本，每一小段斜線是兩本中一段相同的文字。連成一條對角線＝順序抄錄；幾段平行而錯位＝重新編排；斷斷續續＝節錄或增補；只在一小片區域有線＝一方只抄了另一方的一部分。在點圖上拖一個框即放大該區（放大後顯示該範圍內的全部片段），滾輪縮放，雙擊復原；滑鼠停在斜線上看段落的位置，點擊即在右側顯示該段對照；「放大查看」開一個大圖。四角標出當前可見範圍的起止頁行。
  • 圖上方可在「點圖」與「對應帶」之間切換（記住選擇，兩種圖共用放大範圍與所選段落）。對應帶把兩本各畫成一條：上條左欄、下條右欄，每段平行段落是連接兩處的一條帶子。帶子大致平行＝順序抄錄；帶子交叉（紅色）＝移位；條上黃色（左欄）、藍色（右欄）的空檔是沒有對應的部分，即一方刪去或另一方增補之處；金色是所選段落。在上條或下條處橫向拖選即放大那一本的該範圍，另一本隨之對到相應處；滾輪縮放指針所在的一條，觸控板橫滑則平移；雙擊復原。
  • 左側段落列表可按左欄或右欄順序、相似度（高→低、低→高）、篇幅（長→短、短→長）排序。對照表的表頭兼作圖例：左欄的異文塗黃、右欄的塗藍，淡綠是兩本相同；位置欄只在換頁、換行時寫出（同頁只寫行數），完整位置見懸停提示。表格右側的差異分佈條是整段的縮略：左道是左欄的異文、右道是右欄的，框出表格當前可見的部分，點擊或拖動即跳到該處。
  • 點「參數」可以邊拖滑桿邊看點圖和段落的變化。改寫較多時：縮短種子、放寬段內空隙、降低相同比例（或直接選「寬鬆」）；套語多、雜訊多時反過來（「嚴格」）。比較條目、摘錄這類短文字，或要找幾個字的短同文（如兩書各自引用的同一句詔令）時，用「短句」「片語」「詞語」：種子縮短、段落下限降到十字、六字、四字，同時收緊段內空隙和套語上限，免得把零散的巧合和反覆出現的官銜當成同文。書內重複文字多（如實錄的套語、類書的引文）時，調低「套語上限」。
  • 覆蓋率不對稱、措辭上一方系統性地刪去或增入某類內容，是判斷方向的線索；但最終要靠成書年代、作者見聞等外證。

史源考察與版本校勘（多本對校）

  • 多本對校分「同文、異文、校記、統計」四頁。考察史源時先看「同文」：左側「同文分佈」列出各種本子組合共有多少字（如「甲乙同、丙異」若干字），點一行只看該組合的段落；右側是同文段落，可按字數排序、設字數下限，雙擊或回車看各本原文。
  • 最值得注意的是兩類：一是並非各本皆同、只有其中幾本共有的長段文字；二是標「異於底本」的——底本此處讀法不同，而另幾本彼此相同（共有的增文、共同的改字或誤字），往往是判斷誰承襲誰最直接的線索。「匯出 → 給 LLM：史源分析稿」把同文分佈和這兩類段落整理成文檔，交給 LLM 討論史源關係。
  • 「同」以歸一後的文字為準：繁簡、異體、字形差異都算相同；標點不計。同文的判斷都相對於底本的座標，底本沒有的文字只在兩本以上相同時才列出。
  • 底本只是參照系，不影響統計；一般選完整、可靠、或你準備作為整理底本的那一本。
  • 各本範圍不一時，在文本設定裡用頁碼或起止文字截取相同部分。
  • 先看「統計」第三部分的讀法分組，對可能的家族有個印象；再到「異文表」逐條判斷：點某本讀法定為正讀，只給指示性錯誤標 ★。
  • 也可以請 LLM 先判一遍：「匯出 → 給 LLM：判讀稿」生成一份自足的 Markdown 文檔（任務說明、各本、異文表、回答格式），複製或存檔後貼給任何 LLM（Claude、ChatGPT、DeepSeek 等）；把它的回答整個貼回「匯出 → 導入 LLM 的判讀回答」，表格中的正讀與指示性錯誤即變成標記。可以只送未判斷的、或某個編號區間。LLM 的判斷只是初稿，尤其是正讀與指示性，請逐條覆核。另有「譜系討論稿」（附程序的統計與草圖）、兩本對讀的「LLM 分析稿」、檢索結果的「LLM 分析稿」。
  • 判斷過一部分後回到「統計」：共同錯誤的組應當層層包含（如「乙丙丁」⊃「丙丁」）；出現交錯的組，就要考慮交叉傳承或誤判。

聚焦一句話（檢索）

  • 在「檢索」中輸入一句或一段話（如崇禎遺詔「朕死無面目見祖宗於地下」），程序在各文本中找出它的近似出現處：容許異文、脫衍、改寫，簡繁和標點不拘。輸入即檢索；清空輸入框（或按 Esc）即清空結果。「方式」選「模糊」容許異文、脫衍，最低相似度可調（檢索詞很短時，如三字人名，模糊會帶出不少只差一字的地方）；選「精確」只找歸一後字字相同之處。檢索詞不足三字時一律按精確（差一字就是另一個詞）。
  • 與通檢一樣，命中處全部找出、全部計數（每本逾 3000 處才截斷並註明）；結果頂上列出各本命中多少處（點擊跳到那一本）。列表先顯示每本前 30 處（混排時前 200 處），「顯示更多」再展開。
  • 結果可按原文順序或相似度高低排列，可按文本分組或各本混排（混排時每處標出是哪一本）。
  • 結果只是列出，不預先選入。雙擊任一處（或選中後按回車）開彈窗看原文上下文：命中處金色底線，其中與檢索句相同的字塗淡綠；彈窗頂上可「上一處」「下一處」逐處往下看（鍵盤 ← →；看原件時 ← → 是翻頁），列表跟著移動，也可在彈窗裡直接「選入對校」。右鍵可與參照並排看。要逐字對校時，勾選要比較的幾處（先勾的一處為參照，勾選後可改選「參照」），點「對校所選」：各處片段先按參照片段的範圍自動對準，再逐字對校，校記、異文表、統計、匯出都與全文對校相同。每一處可單獨匯出或複製（行末「⋯」），全部或已選的結果可匯出 Word、Excel、TXT。
  • 在這裡做的判讀標記與全文對校共用（按底本中的位置記錄），兩邊可以互相接續。

結果隨選擇而變

  • 各頁顯示的永遠是當前選擇的比對結果：換文本、勾選或取消勾選、改範圍、改設定，都會自動重算（舊結果先淡出，算好後替換）。所以沒有「比對」「清空」按鈕。
  • 要清空就取消選擇：兩本對讀選「（未選）」；多本對校的底本選「（未選）」或關掉全部校本；檢索清空輸入框；總覽取消勾選到不足兩本。

匯出

  • 兩本對讀：本段或全部段落的對照（Word 彩色、Excel、Markdown），平行段落列表（Excel、CSV）。
  • 多本對校：同文表（Excel：同文分佈＋同文段落；CSV），校勘記（Word：底本正文附上標編號＋校記；純文本），異文表（Excel、CSV），TEI P5 XML，CollateX 對齊表，全部數據 JSON。
  • 檢索：全部或已選的結果（Word、Excel、TXT），或單獨一處。
  • 原文上下文（雙擊打開的各本並排頁）：右上「匯出」或右鍵——Word（淡綠＝與參照相同，金色底線＝所選位置，兩本時左右並排）、Excel（每本一行：上文、所選、下文）、Markdown、TXT、複製；PDF 在「原件」狀態時另可把當前頁連同標注存為 PNG。

看原文

  • 右鍵：文本列表（設定、參與比對、放入兩本對讀左欄或右欄、設為底本、打開原文件、在訪達中顯示、移除；空白處加入文件），平行段落（看兩本原文、匯出本段、LLM 分析稿），對照表、校記、異文表、同文、檢索結果、總覽各處也都有相應的常用操作。單擊選中一條後，↑↓ 逐條移動，回車相當於雙擊。
  • 對照表的任一行、校記的任一條、底本中的異文標號、檢索結果的任一處，雙擊即顯示各本在該處的原文上下文（保留原來的分行與頁碼），與參照相同的字塗淡綠；範圍可在 ±80 到 ±2000 字之間切換。
  • 原文上下文裡兩種標記各管一事：淡綠標「異同」（與第一欄參照相同的字），金色底線標「位置」（雙擊進來的那一處）；底線內沒有塗綠的字就是那裡的異文。鼠標懸停或點擊任一欄的一處，各欄把對應的一段加框（與對照表的片段一樣，到異文或句末為止；落在異文處框出整個不同的單位，另一本無字處畫小空框）；不在視區內會自動捲過去。鼠標移到空白處或移出文字框，框即消失；點擊一個字可固定這組框（便於把鼠標移到另一欄去看），再點空白處取消。兩本對讀的對照表中，懸停一段，同一行另一欄的對應段加框。
  • PDF 文本在預覽中可切換到「原件」，看該頁的掃描或排印原貌，核對 OCR 錯字。原件可滾動翻頁、縮放；PDF 帶文字層（含 OCR 層）時，所選位置加框、與參照相同的文字塗淡綠，與文字視圖一致——未塗綠處即異文所在。

注意

  • 簡繁一對多（后／後、发／發／髮、干／乾／幹）在歸一後視為同字；原字形不同時仍記為「字形差異」，不會丟失。
  • PDF 的頁眉、頁碼會混入正文。頁碼數字默認忽略；頁眉文字會表現為零星的「多出」，可在範圍裡截取正文頁，或忽略這類異文。
  • 「疑跳脫」「疑重文」等提示只看字面，比如兩處恰好都有「之」字也可能觸發，請結合文義判斷。

金色底線原文預覽中所選的位置、檢索的命中處；一道金色豎線表示此處無字

相同用淡綠、差異用黃藍：綠色直覺上表示「一致」，飽和度壓低，長段相同的文字不至於喧賓奪主；左右兩本的差異各用一暖一冷的顏色，一眼可分。
